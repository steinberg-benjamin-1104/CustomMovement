A small Unreal Engine project demonstrating custom character movement without the CharacterMovementComponent and a basic data snapshot system inspired by rollback netcode in fighting games. The project includes left, right, and jump keyboard inputs, with functionality to capture and restore movement state. This project is not currently rollback compatible, as input handling is not designed for deterministic rollback simulation. No animation system is included. Blueprint is used for demonstration purposes, but a C++ implementation is recommended for practical use. The goal is to provide a starting point for exploring custom movement and state management in Unreal Engine.
